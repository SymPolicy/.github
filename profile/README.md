# SymPolicy

Organization-wide governance applies to **every** repository under this organization.

## Constitution (binding)

**AI cannot be responsible for code, and therefore must not sign code.**

- Humans who use AI must submit commits under their own Git signature.
- AI/bot-signed pull requests are drafts and must be re-authored by a human before merge.
- Full text: see [`CONTRIBUTING.md`](../CONTRIBUTING.md) and `styio-dev-doc` standards (EN/ZH).
